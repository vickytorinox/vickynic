CÓMO PUBLICAR EN GITHUB PAGES (vicynic.com)

1. github.com → New repository → nombre: vicynic → Public → Create.
2. "uploading an existing file" → arrastrá TODO el contenido de esta carpeta
   (index.html, support.js, CNAME y la carpeta assets) → Commit changes.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: main / (root) → Save.
4. Settings → Pages → Custom domain: vicynic.com → Save. Cuando se habilite, tildá "Enforce HTTPS".
